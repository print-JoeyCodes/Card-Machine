# Card Machine
This is my Week 2 project for Half Life.

I decided to make an automatic card shuffler. I wanted to at first also have it deal cards, but that got too complicated.
Hopefully this machine will be used during family game nights at my house. I also plan to make some changes after Half Life is completed

This is my first time using Onshape so it took me a little to get going. But I have learned alot and am more confident in 3d modeling. But for how good I am,
I will have to wait till I get the prints back.
